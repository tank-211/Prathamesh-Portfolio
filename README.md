# Prathamesh Jadhav — Portfolio

A responsive single-page developer portfolio built with React, Vite, Framer Motion, and Lucide icons.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite.

## Build for production

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`.

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. Import the repository in Vercel.
3. Framework preset: Vite.
4. Build command: `npm run build`
5. Output directory: `dist`

## Before publishing

- Verify the résumé details and update the PDF in `public/Prathamesh-Jadhav-Resume.pdf`.
- Replace the generic GitHub project links with each real repository URL.
- Add live demo URLs only for deployed projects.
- Confirm the availability status and all contact details.
- Add a real contact form backend/service if you need form submissions. The email link currently opens the visitor's email app.
- Confirm current job titles and dates are accurate.

## Notes

The project cards use CSS-built illustrative previews rather than screenshots of the actual applications. This keeps the site self-contained; replace these visuals with genuine screenshots if you want to show the real products.
